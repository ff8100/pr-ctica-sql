Guía de Referencia Técnica SQL

Manual explicativo de sintaxis, conceptos esenciales y comandos para el manejo de bases de datos relacionales.

1. Definición y Manipulación de Datos (DDL & DML)

CREATE TABLE (Crear Tablas)

¿Para qué sirve?: Define la estructura e infraestructura de una nueva tabla, especificando el nombre de las columnas, tipos de datos permitidos y restricciones de integridad.

Sintaxis:

CREATE TABLE IF NOT EXISTS nombre_tabla (
    columna1 TIPO_DATO RESTRICCION,
    columna2 TIPO_DATO
);
  • Tipos comunes: INTEGER (enteros), TEXT (cadenas), REAL (decimales), DATE (fechas).
  • Restricciones: PRIMARY KEY (llave primaria única), AUTOINCREMENT (incremento automático), NOT NULL (obligatorio).

Ejemplo:

CREATE TABLE IF NOT EXISTS departamentos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nombre TEXT NOT NULL
);

INSERT INTO (Insertar Registros)

¿Para qué sirve?: Agrega una o más filas de datos en una tabla existente.

Sintaxis:

INSERT INTO nombre_tabla (columna1, columna2) 
VALUES ('valor1', valor2);

Ejemplo:

INSERT INTO departamentos (nombre) 
VALUES ('Sistemas'), ('Ventas');

UPDATE (Actualizar Registros)

¿Para qué sirve?: Modifica los valores de una o varias columnas en registros ya existentes. Requiere una cláusula WHERE para evitar modificar toda la tabla.

Sintaxis:

UPDATE nombre_tabla
SET columna = nuevo_valor
WHERE condicion;

Ejemplo:

UPDATE empleados 
SET salario = 950.00 
WHERE nombre = 'Carlos Ruiz';

DELETE (Eliminar Registros)

¿Para qué sirve?: Remueve de forma permanente una o varias filas de una tabla basándose en una condición específica.

Sintaxis:

DELETE FROM nombre_tabla
WHERE condicion;

Ejemplo:

DELETE FROM empleados 
WHERE id = 3;

2. Consultas, Filtros y Agregaciones

SELECT y WHERE (Consultar y Filtrar)

¿Para qué sirve?: Recupera datos de una o más tablas y permite filtrar filas específicas según criterios lógicos.

Sintaxis:

SELECT columna1, columna2 AS alias
FROM nombre_tabla
WHERE condicion;
  • Operadores de comparación: =, >, <, >=, <=, <> (diferente).

Funciones de Agregación (COUNT, SUM, AVG)

¿Para qué sirve?: Realizan cálculos sobre un conjunto de valores y devuelven un único valor escalar de resumen.

  • COUNT(*): Cuenta el número total de registros que coinciden con la consulta.
  • SUM(columna): Calcula la suma total de los valores numéricos de una columna.
  • AVG(columna): Obtiene el promedio aritmético de los datos numéricos de una columna.

Ejemplo:

SELECT AVG(salario) AS salario_promedio FROM empleados;

GROUP BY y HAVING (Agrupamiento y Filtro de Grupos)

¿Para qué sirve?: GROUP BY agrupa filas que tienen los mismos valores en filas de resumen. HAVING permite aplicar filtros a esos grupos consolidados (a diferencia de WHERE, que filtra filas individuales antes de agrupar).

Sintaxis:

SELECT departamento, SUM(salario) AS total_depto
FROM empleados
GROUP BY departamento
HAVING SUM(salario) > 1500;

Subconsultas (Subqueries)

¿Para qué sirve?: Una consulta anidada dentro de otra instrucción SQL. Permite evaluar criterios dinámicos que dependen de un cálculo previo.

Sintaxis / Ejemplo:

SELECT nombre, salario 
FROM empleados
WHERE salario > (SELECT AVG(salario) FROM empleados);

ORDER BY y LIMIT (Ordenamiento y Paginación)

¿Para qué sirve?: ORDER BY organiza los datos de forma ascendente (ASC) o descendente (DESC). LIMIT restringe la cantidad máxima de resultados a retornar.

Sintaxis / Ejemplo:

SELECT nombre, salario 
FROM empleados
ORDER BY salario DESC
LIMIT 1;

3. Relación entre Tablas y JOINs

Claves Foráneas (Foreign Keys)

¿Para qué sirve?: Una columna o grupo de columnas que establece un vínculo directo entre los datos de dos tablas. Garantiza la integridad referencial conectando la clave primaria de una tabla principal con una columna de una tabla secundaria.

Sintaxis:

CREATE TABLE empleados (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nombre TEXT NOT NULL,
    departamento_id INTEGER,
    FOREIGN KEY (departamento_id) REFERENCES departamentos(id)
);

INNER JOIN (Cruzar coincidencias exactas)

¿Para qué sirve?: Devuelve únicamente las filas que tienen valores coincidentes en ambas tablas.

Sintaxis:

SELECT empleados.nombre, departamentos.nombre AS departamento
FROM empleados
INNER JOIN departamentos 
ON empleados.departamento_id = departamentos.id;

LEFT JOIN (Priorizar tabla izquierda)

¿Para qué sirve?: Devuelve todas las filas de la tabla izquierda (la primera nombrada) y las filas coincidentes de la tabla derecha. Si no hay coincidencia, devuelve valores NULL para la tabla derecha.

Sintaxis:

SELECT empleados.nombre, departamentos.nombre AS departamento
FROM empleados
LEFT JOIN departamentos 
ON empleados.departamento_id = departamentos.id;

RIGHT JOIN y FULL OUTER JOIN

¿Para qué sirve?:

  • RIGHT JOIN: Devuelve todos los registros de la tabla derecha y las coincidencias de la izquierda.
  • FULL OUTER JOIN: Devuelve todos los registros cuando hay una coincidencia en la tabla izquierda o derecha.

Nota sobre SQLite: SQLite no admite la sintaxis nativa de `RIGHT JOIN` ni `FULL OUTER JOIN`, pero estos se simulan mediante la combinación de `LEFT JOIN` y el operador `UNION`.
